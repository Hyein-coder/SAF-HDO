# Endpoint-composition survey: source register and search log

Date searched: 2026-11-17. Companion synthesis: [endpoint-composition literature survey](261117_endpoint_composition_literature_survey.md).

## Protocol and evidence handling

Question: which methods support fitting measured final product distributions and constructing an HDO process model from endpoint data?

Coverage: no lower year cutoff; studies discovered through 2026-11-17. English-language primary papers, original institutional records and process-design reports. Broad discovery used web search, followed by publisher/institutional pages, selected full texts, citation following and direct Crossref metadata requests. No Scopus or Web of Science export was performed.

Included subjects: endpoint distributions, SimDist/TBP characterization, representative-mixture optimization, specified-yield/stoichiometric process blocks and endpoint HDO assays. Excluded as core evidence: kinetic parameter estimation, catalyst screening without relevant composition data, unrelated Weibull applications and HEFA presented as a direct proxy for pyrolysis-oil HDO.

Records were consolidated by DOI, then title for reports. Repeated search hits and repository/preprint versions are not independent studies. The register contains 12 core papers and one design report. Discovery-result counts and the number of duplicate search hits were not retained; no PRISMA screening counts are claimed.

Access labels: **FT** = relevant methods inspected in full text; **AB** = primary publisher/institutional abstract inspected, with limited method detail; **PART** = partial original text available, no complete method audit; **META** = bibliographic confirmation only, not substantive evidence. Detailed claims in the synthesis are restricted to the access depth recorded here. Notes are paraphrases, not copied abstracts.

## Analytical-method references

- [ASTM D2887-24](https://store.astm.org/d2887-24.html): official public method-description page; boiling-range distribution, not molecular speciation. The actual method used for our dataset is unconfirmed.
- [SCION Instruments, Analysis of Boiling Point Distributions in Petroleum Fractions using Simulated Distillation](https://scioninstruments.com/wp-content/uploads/2020/12/0008_ASTMD2887_SimDist.1.pdf): original instrument-provider application note describing n-paraffin retention-time/boiling-point calibration. This is method implementation evidence, not a peer-reviewed HDO study.

## Access and reproducibility limits

Selected PDF text extraction followed the PDF-reading workflow. Full texts for D4 and M3 were downloaded to `D:\saf_hdo\tmp\endpoint_survey` and extracted with the existing `pdftotext` installation. No package installation or fitting-code change was required. Most other evidence is abstract-level; complete tables, supplementary data, parameter uncertainties and detailed algorithms were not audited.

The search is broader in modeling approach than the previous kinetic survey, but it is still a focused scoping review. Journal prestige, citation counts and access status were not used as substitutes for methodological relevance. No universal best distribution, unique reaction network or literature novelty claim is established.
